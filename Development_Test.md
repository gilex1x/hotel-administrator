# **Development Test – NTS** 

Se tiene la necesidad de gestionar la búsqueda y calificación de una cadena de hoteles, para esto se deben desarrollar, un Backend en .Net Core el cual expondrá una API REST y una aplicación Frontend para la integración de los datos y la visualización de los usuarios y administradores. 

Para el ejercicio no es necesario crear un diseño de interfaz (UI) avanzado, sin embargo, debe ser responsiva de manera que las páginas se visualicen adecuadamente en cualquier pantalla. 

# **Ejercicio 1: API Rest** 

Construir un API REST en .Net Core con las siguientes funcionalidades 

1. CRUD para el control de los hoteles con un administrador. 

2. Listar y filtrar los hoteles por Nombre y/o Calificación. 

_*A la hora de diseñar la estructura de la aplicación, tener en cuenta factores como escalabilidad, reutilización y separación de responsabilidades._ 

_*Considerar también el uso de configuraciones para ajustar como se ejecuta la aplicación en entornos productivos y de desarrollo._ 

# **Ejercicio 2: Frontend** 

Construir un proyecto en Angular para 2 tipos de usuarios (Administrador y Usuarios) 

**1. Administrador:** Debe poder crear hoteles, listarlos, editarlos, eliminarlos. 

**2. Usuario:** Crear una landing page pequeña, dando introducción a la cadena de hoteles, donde se van a listar todos los hoteles, se pueden realizar búsquedas por calificación o nombre. 

_*Consumir la API desarrollada en el ejercicio anterior, implementando las funcionalidades necesarias para listar y filtrar los hoteles._ 

# **Entrega** 

La entrega se realizará por medio de un repositorio GIT público. Se debe subir su solución al repositorio y compartir la url.
